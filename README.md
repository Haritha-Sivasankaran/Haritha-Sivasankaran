### Selected Systems & Architecture

#### [TransitPulse 2.0](https://github.com/Haritha-Sivasankaran/TransitPulse-2.0)
*Distributed transit telemetry ingestion & real-time notification engine*
- **Architecture**: Ingests high-frequency vehicle telemetry streams through **Apache Kafka** topic partitions, decoupling ingestion throughput from client delivery.
- **Delivery**: Broadcasts state mutations to subscribed web clients via persistent **WebSocket** connections backed by a lightweight **Node.js** event loop.
- **Frontend**: Renders dynamic vehicle positions, route alerts, and transit latency metrics using a reactive **React** dashboard.
- **Stack**: `Apache Kafka` · `Node.js` · `Express` · `React` · `WebSockets` · `Docker`

#### [Obsidian Chess](https://github.com/Haritha-Sivasankaran/Obsidian-Chess)
*Modular offline-first chess engine with algorithmic move evaluation*
- **Engine**: Implements game-tree search using **minimax with alpha-beta pruning**, board position evaluation heuristics, and move validation.
- **State Management**: Zero-dependency immutable board state trees supporting linear undo/redo histories and branching variant simulations.
- **Client**: Native HTML5 Canvas rendering engine with custom board themes and offline local-storage persistence.
- **Stack**: `Vanilla JavaScript (ES6+)` · `HTML5 Canvas` · `CSS3` · `Local Storage API`

#### [Automated Telemetry Pipeline](https://github.com/Haritha-Sivasankaran/Haritha-Sivasankaran)
*GitHub GraphQL telemetry ingestion and vector asset synthesis*
- **Data Engine**: Headless **Python** pipeline querying the GitHub GraphQL API to compute contribution rhythms, active streaks, language byte distributions, and commit momentum.
- **Automation**: Scheduled **GitHub Actions** cron running every 6 hours to synthesize fresh, production-grade SVGs and deploy live JSON telemetry to GitHub Pages.
- **Stack**: `Python 3.12` · `GitHub GraphQL API` · `GitHub Actions` · `SVG Synthesis`
