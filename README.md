### 💡 About Me

I am a full-stack engineer focused on architecting resilient backend services, event-driven pipelines, and intuitive, fluid user experiences. I specialize in building end-to-end systems across the modern JavaScript/TypeScript ecosystem, Java enterprise layers (Spring Boot & Spring AI), and Python data services.

- 🔭 **Current Focus**: Designing high-throughput event streaming architectures and real-time telemetry dashboards.
- ⚙️ **Backend & Cloud**: Java (Spring Boot, Spring AI), Python, Node.js, RESTful microservices, and Docker containerization.
- 🎨 **Frontend Craft**: React, TypeScript, Next.js, and modern component systems with strict layout fidelity.
- ⚡ **Asynchronous Messaging**: Event-driven streaming with Apache Kafka & RabbitMQ.
- 🧠 **Engineering Principles**: Clean architecture, test-driven reliability, modularity, and automated CI/CD pipelines.
